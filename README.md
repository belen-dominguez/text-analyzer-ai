# Text Analyzer AI

Web app para analizar texto usando IA. Permite resumir, mejorar la redacción y clasificar cualquier texto.

## Stack

- **Backend:** Python + FastAPI + OpenAI
- **Frontend:** HTML + CSS + JavaScript
